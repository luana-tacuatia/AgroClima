# Questionário rápido com potenciais usuários do AgroClima

Público: agricultores, familiares ou conhecidos que trabalham no campo ou planejam atividades ao ar livre.
Duração: cerca de 5 minutos. Não coletar nome, telefone nem endereço.

Como aplicar: mostrar no celular a página de comparação (`/comparar`) de uma cidade próxima,
com o bloco "Como ler a concordância" fechado, e fazer as perguntas na ordem.

1. Você costuma consultar a previsão do tempo para decidir alguma atividade (plantar, irrigar,
   pulverizar, colher, outra)? ( ) Sim, sempre ( ) Às vezes ( ) Não
2. Já percebeu que aplicativos diferentes mostram previsões diferentes para o mesmo dia?
   ( ) Sim ( ) Não ( ) Nunca comparei
3. Olhando a tela, em qual variável as duas fontes discordam mais? (anotar se a pessoa
   identificou corretamente a variável com selo "Baixa") ( ) Acertou ( ) Errou ( ) Não soube
4. O que você entende quando aparece "Baixa concordância" na chuva?
   (anotar a resposta com as palavras da pessoa)
5. Essa informação mudaria alguma decisão sua? ( ) Sim ( ) Talvez ( ) Não — Qual?
6. De 1 (muito difícil) a 5 (muito fácil), quão fácil foi entender a tela? 1 2 3 4 5

Registro: anotar as respostas em uma planilha (uma linha por pessoa) e enviar para o grupo.
Com 5 a 10 pessoas já é possível relatar o resultado como sondagem exploratória.
